# 平台能力设计评审

评审基准：Star-letter SDK **2.7.2 / docs rev44**，实现于2026-11-13，初次验收于2026-11-14，音乐替换复核于2026-11-15。rev44的storage/exchange合同与此前rev43一致。实际使用能力为 `storage` 与 `exchange`；不调用 AI、排行榜、联机或运行时上传。

## storage

| 条目 | 结论 | 代码证据与处理 |
|---|---|---|
| S1 单值容量 | pass | `platform.js` 写入前以 UTF-8 计算完整包字节，超过 50,000 字节即拒绝；远低于文档 16MB 上限。图片、剧情配置不进入存档。 |
| S2 key 数量 | pass | 一个固定 `user` key，无 `game` scope，无动态 key。 |
| S3 频率和时机 | pass | 单一串行入口 `saveProgress`，无周期轮询或逐渲染帧写档。`app.js`在收集证据、解谜、推进、对话后以1.2秒防抖保存；手动保存和页面隐藏时保存。广告发货必须立即等待保存。 |
| S4 scope | pass | `get/set` 显式 `scope: 'user'`；玩家进度不会跨玩家共享。 |
| S5 多端与冲突 | pass | 依现行直写语义直接 `set`，无 CAS 循环。平台路径不写 `localStorage/IndexedDB`；仅独立页面有明确本机模式。完整 `saveMeta` 随写提交。 |
| S6 错误韧性 | pass | 每次 SDK 异步调用有捕获和 `isPlatformSDKError` 判断。覆盖容量、配额、频率、登录、读取、写锁及 stale generation。读取失败 throw 且锁止写入；保存失败保留内存态并报告。 |
| S7 数据设计 | pass | 包和引擎均有版本；旧裸 v1 档可迁入包。存档只含行动状态与广告收据，不含剧情/素材副本；派生对话分数与结局由 `restoreState` 重建。实际浏览器保存/刷新/续玩验证保持章节、解题、末轮意愿与结局。 |

平台独立页面使用本机存档，是显式的非平台运行模式。iframe 模式失败时不会切换到它。

## exchange：只启用广告提示路径

| 官方自检项 | 结论 | 证据与处理 |
|---|---|---|
| 真实项目列表和播放 | 配置pass；真实视频未实测 | 已创建 `friendship_hint` 广告项（10588 / 8479，审核通过并上架）；代码通过 `listItems` 动态发现并显式传 `via: 'ad'`。平台临时宿主模拟广告发货和刷新恢复通过；浏览器未登录，真实播放尚未实测。 |
| 取消、失败、成功后恢复 | pass | `showRewardedHint` 的 `finally` 无条件清除 `adBusy/paused`；单测覆盖取消、失败、超时。 |
| 发货等待持久化 | pass | `deliver` 等待 `onReward`，并核实本次订单已进入成功存档收据；失败抛出，不正常返回。 |
| 同订单重复回调与刷新 | pass | 独立收据保存 `ad:<adOrderId>`；同存档原子写入。单测重新建立 bridge、读云档后再次回调仍只加一次。 |
| 网络异常不自动重试 | pass | 无自动重试逻辑，入口并发锁与 15 秒主动冷却；未知结果要求玩家检查提示次数后再主动操作。 |
| 持久化订单凭据 | pass | 收据保留 `bizId`、`adOrderId`，存在时也保留 `exchangeOrderId`；不会因重开剧情删除。 |
| 星光币确认失败的退款收口 | 不适用 | 本作只调用广告路径，配置 `costAmount=0`，不发起星光币冻结或付费订单。不得把本封装直接改成付费商城而不实现 `orderStatus` 收口。 |
| 已购恢复 feature-detect | 不适用 / 明确取舍 | 不售卖买断权益；提示是消耗品，成功发货必须与当前进度同档持久化。未调用 `ownedItems`，不依赖旧宿主缺失的方法。 |
| 消耗型账本重放 | 不盲目重放 | 保存已发货与已消费后的剩余次数；不以历史订单总数重建剩余提示，避免把已消费提示全部重新发放。收据 256 笔后停止新增广告，保留全部去重事实。 |

## 验证证据

`node --test tests/platform.test.js`：12 项通过，涵盖保存失败、读取失败及重试、账号切换、广告取消与失败、持久化去重、刷新恢复、并发点击、并发重复回调和派生字段剔除。测试使用隔离宿主，不能替代真实广告播放与平台预览验收。

`star-letter check`、完整主线与三结局的实际浏览器测试均已通过；草稿上传成功且20个CDN文件与本地SHA-256全部一致。完整证据与验证边界见[VERIFICATION.md](VERIFICATION.md)。正式公开发布不在本次交付范围。

## 1.1.0 音乐替换复核

新增3个静态AAC/M4A音轨，不使用sdk.oss，不增加玩家存档字段或平台调用。存档版本仍为v1，原有玩家进度兼容；saveMeta中的gameVersion更新为1.1.0。音轨相对路径随目录整体上传，24个产物共约12.33MB，单曲最大约4.36MB；广告和后台状态暂停HTMLAudio播放，恢复后保留位置。平台能力声明维持storage/exchange，AI/OSS维持关闭。结构预检无警告。
