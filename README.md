# 未发送的我们

**一部旧手机，一场迟到七年的对话。**

![《未发送的我们》封面](assets/cover.webp)

《未发送的我们》是一款原创中文旧手机调查与友情叙事游戏。你扮演周遥，收到失联好友沈知夏寄来的旧手机。聊天记录、合照、账单与没有发送的草稿里，留着2019年“雨声放映计划”决裂前后的细节。

一笔未经同意挪用的维修预付款、一场临时取消的放映、被删除的共同录音，以及两边都说出口的气话。你要做的是把它们放回真实的顺序，再决定今天如何面对彼此。

## 游戏内容

- **5章调查**：在聊天、相册、备忘录和账单之间交叉核对。
- **20条证据、4道推理题**：从日期密码到资金时间线，每个答案都有可查找的依据。
- **132条手机消息**：读到两个人怎样亲近，也怎样在“我来处理”与“随便你”之间走散。
- **6轮重逢对话、3个完整结局**：重新联系、保留距离、认真告别。最后明确表达的边界会被尊重。
- **三首场景配乐**：由创作者通过 Stable Audio 生成，分别用于调查、重逢和结局；自动淡入淡出，调查与重逢循环，结局自然结束。
- **声音控制**：首次点击后开始播放；关闭声音、切到后台或观看广告时暂停，恢复后接着播放。雨声试听与交互提示音独立混音。

全部主线和三个结局均可免费完成。广告仅提供玩家主动领取的额外调查提示，不锁剧情、不改变结局。

## 本地启动

需要 **Node.js 20或更新版本**。

```bash
npm ci
npm run dev
```

在浏览器打开 [http://127.0.0.1:7438](http://127.0.0.1:7438)。可通过 `PORT` 环境变量修改端口。项目为原生 JavaScript ES modules 与静态网页，无需配置业务后端。

测试、构建与检查：

```bash
npm test
npm run build
npm run check
```

构建结果位于 `dist/`，页面与素材使用相对路径。实际浏览器、平台云档、广告与发布验证记录见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。

## 存档与星匣草稿

独立打开的网页使用当前浏览器的**本机存档**；在星匣宿主内运行时使用 **GameSDK 云存档**。平台初始化或读取失败时，会显示错误并阻止覆盖存档，不会悄悄切成本机模式。独立页面不提供平台广告。

本作已建立星匣创作者草稿项目 **10588**；[星匣项目入口](https://game.virtualoverapp.com/game/10588)可能需要创作者权限。当前状态为**草稿，未正式公开发布**，此链接不代表公开可玩版本。

可选广告提示兑换项 **8479** 已配置并审核通过，每次完整观看按平台确认发放一个额外提示。配置通过与真实广告播放是不同的验收项目，实际播放、奖励持久化及云存档结果以 [验证记录](docs/VERIFICATION.md) 为准。接入说明与能力评审见 [PLATFORM.md](docs/PLATFORM.md) 和 [CDR.md](docs/CDR.md)。

在已登录且配置正确的 Star-letter CLI 环境中，保留草稿发布方式：

```bash
star-letter publish --draft
```

正式公开发布需要另行执行平台发布流程。

## 原创内容与参考范围

本作参考 [A Normal Lost Phone](https://accidentalqueens.com/press/a_normal_lost_phone/) 的跨应用调查组织，以及 [Emily is Away](https://store.steampowered.com/app/417860/Emily_is_Away/) 通过聊天表达关系变化的方式。

周遥、沈知夏、“雨声放映计划”、资金争议、录音事件、全部对白与结局均为本项目原创创作。参考范围限于玩法与叙事表达的方法，没有复制上述作品的原角色、故事、文本、美术、界面素材或音频。

项目包含 **13张内置AI图像工具生成的原创位图**：1张封面、2张角色人像、6张相册照片、3张结局图和1张应用图标图集；使用 WebP 格式，未以SVG、emoji或图库素材代替这组美术。照片中的日期、手写内容与证据以游戏内可读文字呈现。完整生成prompt记录见：

- [封面素材](docs/ASSET-PROMPTS-cover.md)
- [角色与结局素材](docs/ASSET-PROMPTS-characters.md)
- [相册素材](docs/ASSET-PROMPTS-photos.md)
- [应用图标素材](docs/ASSET-PROMPTS-icons.md)

三首配乐由创作者通过 **Stable Audio** 按本项目提示生成并提供，使用AAC-LC/M4A网页版本，完整时长分别为3:00、2:00、1:30，合计约9.01MiB。原始WAV未修改、不收入仓库。曲目来源与编码记录见 [MUSIC.md](docs/MUSIC.md)。雨声试听和短提示音仍由 `src/audio.js` 单独生成，不叠加原先的程序化背景旋律。剧情时序与推理链见 [STORY.md](docs/STORY.md)。
